# 🏥 Hospital Management System

A simple console-based Hospital Management System built with Python.
This project demonstrates the use of dictionaries, user-defined functions,
and the datetime module to manage core hospital operations.

### Features
- Register new patients with auto-captured date & time of registration
- Register doctors with their specialization
- Schedule appointments between registered patients and doctors
- View detailed patient, doctor, and appointment records

### Tech Stack
- Language: Python 3
- Modules: datetime (built-in)

### How to Run
1. Clone the repository
2. Run `python hospital.py` in your terminal
3. Follow the on-screen menu to navigate the system

### Concepts Used
- Dictionaries and nested data structures
- User-defined functions
- Input validation and error handling
- datetime formatting
